# 本地开发

当前主应用仍保留未登录本地模式：画布、部分旧素材入口和 AI API Key 可以保存在浏览器本地。`saas/multi-user` 分支新增了 `server/` 后端，登录后 AI 请求会走后端模型网关代理和额度系统；模型网关只连接 NewAPI，OpenRouter 渠道在 NewAPI 后台配置。

## 1. 启动前端

```bash
cd web
bun install
bun run dev
```

前端默认访问：

```text
http://localhost:3005
```

## 2. 配置模型

未登录本地模式可以打开右上角配置弹窗，填写自己的 `Base URL`、`API Key` 和模型名。登录后的 SaaS 路径不读取浏览器里的模型 Key，而是通过 Go 后端访问 NewAPI。

第三方提示词由 Next.js route 拉取并缓存在运行实例内存中；WebDAV 可选择前端直连或 Next.js 转发。

## 3. 启动后端

本地后端需要 PostgreSQL：

```bash
cd server
go run ./cmd/api
```

常用环境变量：

```env
SERVER_ADDR=:8085
DATABASE_URL=postgres://infinite_canvas:infinite_canvas@localhost:5432/infinite_canvas?sslmode=disable
MODEL_GATEWAY_PROVIDER=newapi
MODEL_GATEWAY_BASE_URL=https://你的-newapi-域名/v1
MODEL_GATEWAY_INTERNAL_URL=
MODEL_GATEWAY_TOKEN=你的平台 token
MODEL_GATEWAY_TIMEOUT_SECONDS=600
STORAGE_PROVIDER=local
LOCAL_STORAGE_DIR=data/media
WORKER_ENABLED=false
WORKER_CONCURRENCY=1
WORKER_POLL_SECONDS=3
DEFAULT_LOCALE=zh-CN
```

前端开发时如果希望 `/api/server/*` 转发到后端，启动 `web` 前设置：

```bash
SERVER_API_URL=http://localhost:8085 bun run dev
```

## 4. 启动文档站

如果需要单独调整文档站，在 `docs` 目录执行：

```bash
bun run dev
```

## 常见场景

- 改画布、页面和交互：主要看 `web/`
- 改账号、额度、后台、媒体和模型网关代理：主要看 `server/`
- 改提示词缓存或 WebDAV 代理：主要看 `web/src/app/api/` 和 `web/src/app/webdav-proxy/`
- 改文档站内容：主要看 `docs/content/docs/`
