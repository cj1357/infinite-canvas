# 接口响应

后端业务接口默认返回统一结构：

```json
{
  "code": 0,
  "data": {},
  "msg": "ok"
}
```

- `code = 0` 表示成功。
- `code != 0` 表示失败，通常与 HTTP 状态码一致。
- `msg` 放中文错误提示。
- `data` 放业务数据，失败时可以为空。

AI 代理接口 `/api/server/ai/*` 会尽量保留 NewAPI / OpenAI 兼容响应体，方便前端沿用现有解析逻辑。额度不足、未登录、后台权限不足等由本项目后端直接拦截并返回统一错误结构。

## 常见状态

- `401`：未登录或 session 失效。
- `402`：额度不足、权益过期或当前窗口额度不足。
- `403`：普通用户访问后台接口。
- `404`：当前用户名下不存在该数据。
- `502`：NewAPI 请求失败或后端无法连接 NewAPI。
