- 参考图组交互修复：本地画布图片可在参考图组编辑器中手动加入参考，加入时会先上传为后端媒体；预览按钮会兼容后端返回空 warnings / enabledReferences 的情况，不再触发页面错误覆盖层；参考意图行改为分层布局，避免角色、权重和启用开关在窄面板中重叠；来源卡片会记录画布节点关联，刷新或编辑参考意图后仍能识别已加入状态。
- 参考图组局部意图：同一张画布来源图可继续添加整图参考、构图参考、局部框选参考和风格参考；局部框选会保存 `cropJson`，意图行显示裁剪缩略图，支持删除单条参考意图，编译预览文本会输出 crop 坐标。
- 参考图组编排稳定性：编译预览的提示词和预览结果会由画布页保存草稿，拖动节点或面板短暂重绘后不应再丢失预览内容。
- SaaS 拦截与网关收网：彻底移除了前端直连和WebDAV连接方式，AI 请求强制走后端网关，加强了SaaS登录拦截体验。
- 模型专属矩阵（Google Vertex AI）：模型矩阵全面适配 Google 生态。文本预设为 Gemini 3.5 Flash；生图预设为 Nano Banana 2 (Gemini 3.1 Flash Image) 系列；视频预设为 Google Veo 3.1（包含 Fast/Lite 版本）；音频预设为 Gemini 3.1 Flash TTS。
- Google 图片规格适配：生图和图生图请求会把像素尺寸转换为模型支持的 `resolution` 与 `aspect_ratio`，不再向 Gemini 图片模型发送 `1280x720` 等无效裸尺寸；设置面板只展示当前模型支持的分辨率和标准宽高比，需人工验证 Lite 1K、Flash 2K/4K 与参考图编辑。
- 生图工作台模型能力适配：移除 Gemini 2.5 Flash Image，修复长模型名称显示；切换模型时从 OpenRouter 读取 Google Vertex endpoint 的分辨率、宽高比和参考图能力，仅展示并发送当前模型支持的参数，OpenRouter 不可用时回退具体模型的本地能力记录。
- 网关路由智能兼容：在后端 `joinGatewayURL` 中实现智能校验，自动补齐缺失 of /v1 或 /v1beta 路径，解决生图代理返回 HTML 网页导致的白屏 Bug。
- 个人创作 SaaS 前端：修复了生图工作台及画布点击“加入我的素材”无法同步至云端数据库的 Bug，通过 Zustand Action 自动同步镜像上传，并在“选择素材”弹窗中实现本地与云端素材归一化合并与去重。
- 本地管理员初始化：本地 Compose 会把 `BOOTSTRAP_ADMIN_EMAIL` 注入后端；已将现有 `orange` 账号提升为管理员并清理自动化测试管理员，需确认重新进入页面后可见“后台管理”入口。
- 本地调试优化：在前端 `package.json` 中新增 `dev:3006` 调试脚本，并在 `web/` 下配置 `.env.local` 代理至 `http://localhost:8085` 后端服务，方便本地并发调试。
- 视频模型映射更新：在前端配置 `use-config-store.ts` 中，将 Google Veo 视频模型由原来的 `google/veo-3.1`, `google/veo-3.1-fast`, `google/veo-3.1-lite` 调整为更准确 of Vertex AI 官方 ID（且由于 New API 渠道限制，去除了 `google/` 前缀）：`veo-3.1-generate-001`、`veo-3.1-fast-generate-001` 以及 `veo-3.1-lite-generate-001`。
- 视频模块移除 (方案 B)：物理删除了“视频创作台”页面及相关的 WebDAV 同步服务；在全局导航、首页快速入口中移除了视频页面入口。在画布配置节点中屏蔽了“视频”生成模式，在连线生成菜单中排除了“视频生成”节点类型，在拖拽和上传中限制视频文件；同时在 Go 后端屏蔽了 `/ai/videos` 网关代理路由。旧画布视频节点在前端保持只读播放兼容，规避数据损坏与系统崩溃。
- OpenRouter 参考图统一转发：生图工作台和画布的参考图／蒙版请求仍调用本项目 `/api/server/ai/images/edits`，后端会把 multipart 图片转换为 `input_references` JSON 并经 NewAPI `/images/generations` 发送；需测试工作台单图、画布单图／多图／重试和近似蒙版编辑，确认普通无参考图生图不受影响。
- OpenRouter Google Vertex 路由：后端会在普通生图和参考图转换后的 JSON 请求中主动附加 `provider.only: ["google-vertex"]`，适配 NewAPI 的请求透传；需在开启请求透传的渠道下分别验证文生图和带参考图生图均由 Google Vertex BYOK 路由。
- 生图工作台预览比例：生成结果卡片会按图片原始比例展示，不再把横图或竖图裁成方图；需刷新 `localhost:3006/image` 后分别查看横图、竖图和方图预览。
- 画布生图模型能力适配：提示词浮层的模型名会完整展示，图片节点的提示词浮层会预留模型和参数控件空间，生成配置节点会把模型选择与参数摘要拆成两行；切换生图模型后会先读取模型能力，只显示该模型支持的分辨率和宽高比。画布批量生成会将每张图拆成独立请求，因此仍可选择 1–15 张，并在生成、重试、参考图编辑和蒙版编辑请求中携带同一份能力参数。需刷新画布后依次切换三个 Gemini 生图模型验证。
- 画布图片组标识：悬停图片不会再改变全局图片编号；图片组主卡显示“第 N 组 · N 张”并用于展开／收起，主卡不占用图片序号，组内实际生成图会连续编号。需在含两个以上图片组的画布中悬停、展开和收起各组，确认图片编号连续稳定。
- 画布节点悬浮工具条：单选节点会保留上方操作区，鼠标离开节点后有短暂缓冲，方便移动到右侧按钮；悬停其它节点时工具条仍会优先切换，点击画布空白处会收起。需在节点重叠、靠近和普通单节点场景下验证工具条不会误挡操作。
- 画布图片 AI 工具：图片节点工具栏默认显示“超分”和“多角度”；“超分”会走图生图链路生成新的高清重绘节点，“超分”和“多角度”生成前都可选择生图模型、分辨率和宽高比，并按模型能力展示参数。需分别验证参数切换、Google Vertex BYOK 路由、生成成功和失败提示。
- Compose AI 代理稳定性：长耗时图片生成请求会优先走 Next 显式 API route 转发，通用 `/api/server/*` rewrite 已退到 fallback，避免 30 秒左右被 Next 内置代理截断；最长等待时间统一为 10 分钟。需验证普通生图、超分和多角度生成在 30 秒以上、10 分钟以内仍能等待模型结果。
- 图片生成异步任务化：生图工作台、画布直接生图、参考图编辑、蒙版编辑、超分和多角度都会先创建 `GenerationRun` 后台任务，参考图会先上传为 `MediaObject`，worker 再转换为 OpenRouter `input_references` 并主动带上 `provider.only: ["google-vertex"]`；本地 Compose 默认开启 worker。需验证普通生图、图生图、超分、多角度的排队/轮询/成功展示、失败退款、历史记录和 NewAPI/OpenRouter 日志。
- 画布图片信息：图片节点信息弹窗会区分“图片像素”和“画布尺寸”，避免超分后误把画布展示尺寸当作真实图片分辨率；需验证原图与超分图的信息弹窗是否能正确展示真实像素。
- 画布文本生成：`/responses` 代理返回普通 JSON 时会直接解析 `output_text`，避免 NewAPI/OpenRouter 已成功返回但画布文本节点显示“没有返回内容”；需验证参考图反推提示词、普通文本续写和 Agent 文本问答。
- 画布生成任务节点：参考图组改为可选，节点会自动读取上游文本和图片；连接参考图组时会自动使用该参考图组，连接普通图片时会作为临时参考提交。模型和参数控件复用画布生图能力面板，创建任务前会读取模型能力并发送对应的分辨率、宽高比和输出数量参数。需验证无参考图组纯文本生图、连接图片图生图、连接参考图组生图。
- 画布生成任务图片组：生成任务不再自动创建独立结果组节点；多张输出会像普通生图一样创建图片组，主卡负责展开/收起，组内每张候选图对应一个独立异步 `GenerationRun` 并并行提交。需验证 1 张、3 张和 4 张以上输出时的图片组布局、成功/失败混合展示、停止和重试。
- 本地 Compose 生成 worker：本地 `docker-compose.local.yml` 默认 worker 并发调整为 3，方便生成任务图片组的多个候选并行处理；生产环境仍可通过 `WORKER_CONCURRENCY` 自行配置。需验证本地重建后 3 张候选会同时进入 NewAPI/OpenRouter 日志。
- 画布媒体云端化：登录后保存画布前会把仅存在于浏览器本地的图片节点自动补传为后端 `MediaObject`，并将节点内容与参考图记录改为稳定的 `/api/server/media/:id`；重新加载画布时优先使用 `mediaObjectId`，避免不同浏览器打开同一画布时只看到破图。二次生图、局部编辑、超分、多角度和重试生成结果也会写入 `mediaObjectId`；当前浏览器读不到旧本地 `blob` 时会跳过云端保存，避免把坏链接覆盖回云端。需在原浏览器打开一次含旧本地图的画布，等待保存后再用新浏览器登录验证图片、图片组、二次生成图和重试参考图是否可见。
