# 待测试

- Codex App 插件文档：新增插件安装教程，区分 AI 自动安装、手动安装和本仓库开发调试安装；同步优化插件 README 与技能说明。
- 配置与用户偏好：每个模型渠道新增 OpenAI / Gemini 调用格式选择，默认 OpenAI，切换默认格式时同步更新默认 Base URL；渠道 Tab 增加紧凑醒目的提醒，说明模型是否可选需要到“模型”Tab 选择。
- Gemini 调用格式：支持拉取 Gemini 模型列表，并用于文本问答、在线 Agent 工具调用、基础生图和图生图请求。
- 音频和视频生成：选择 Gemini 调用格式时先给出不支持提示，仍需使用 OpenAI 兼容渠道。
- 多账号 SaaS 后端：新增 Go + Gin + GORM 后端，支持账号 session、云端数据接口、媒体上传、NewAPI 代理、三层额度、后台手动开通和支付预留表。
- 个人创作 SaaS 后端：新增媒体对象、创作素材、参考图集合、参考图意图、生成运行、生成输出、生成任务、模型能力和 Prompt 模板领域表，并同步数据库文档。
- 个人创作 SaaS 后端：新增创作领域仓储方法，支持媒体、素材、参考图集合、参考图意图、生成运行、生成输出、生成任务、模型能力、Prompt 模板的基础读写和生成任务认领。
- 个人创作 SaaS 后端：媒体上传改为 `MediaObject` 主路径，按媒体 ID 生成 R2/local 对象路径，支持上传大小限制、MIME 探测、图片尺寸记录、按 ID 读取和删除。
- 个人创作 SaaS 后端/前端：模型请求入口改为 `MODEL_GATEWAY_*` 配置，新增后台模型网关配置页和连接测试，应用只连接 NewAPI，OpenRouter 渠道由 NewAPI 内部管理。
- 个人创作 SaaS 后端/前端：新增模型能力、计费规则和 Prompt 模板后台配置；计费估算支持基础额度、输出数、参考图数、分辨率倍率和质量倍率。
- 个人创作 SaaS 后端/前端：新增 ReferenceSet 和 ReferenceIntent API，支持参考图角色、权重、排序、所有权校验和编译预览，并提供前端 typed client。
- 个人创作 SaaS 后端/前端：新增 GenerationRun、GenerationJob 和 PostgreSQL worker，支持创建生成任务、预扣额度、调用模型网关、保存常见图片输出、结算/失败退款和前端 typed client。
- 多账号 SaaS 前端：画布项目登录后优先从 `/api/server/canvas-projects` 加载和保存，本地 Zustand 只保留运行时状态与未登录 fallback；画布节点类型新增媒体、提示词、参考图组、生成任务、结果组和便签等领域引用字段。
- 个人创作 SaaS 前端：画布新增 ReferenceSet 节点与编排浮层，可创建参考图组、从已连接的云端媒体节点自动生成 ReferenceIntent、编辑角色/权重/备注，并调用编译预览。
- 个人创作 SaaS 后端/前端：新增 GenerationRun detail 接口，并在画布新增 Generation 节点和 ResultGroup 节点；生成节点可创建/取消/重试后端任务、轮询 run/job/outputs，成功后自动展示结果组。
- 个人创作 SaaS 后端/前端：素材库升级为云端 CreativeAsset，支持上传媒体生成素材、编辑标签/收藏/评分、删除素材、从结果组保存生成输出为素材，并在参考图编排器中把素材加入当前 ReferenceSet。
- 多账号 SaaS 前端：新增会员账号页和后台用户页；登录后图片、文字、音频和 OpenAI 兼容视频请求会走 `/api/server/ai/*`，未登录继续使用本地直连模式。
- Docker 部署：根目录 Compose 调整为 web、server、postgres 三服务，并预留 R2 / NewAPI 环境变量。
