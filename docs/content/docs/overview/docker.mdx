# Docker 部署

如果你希望在自己的机器或服务器上运行项目，可以直接使用 Docker Compose。

## 使用发布镜像

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
docker compose up -d
```

启动后访问：

```text
http://localhost:3000
```

## 本地构建镜像

如果需要基于当前源码构建镜像：

```bash
docker compose -f docker-compose.local.yml up -d --build
```

## 文档站镜像

文档站位于 `docs/` 目录，按带服务端能力的 Next.js standalone 应用单独构建，不打进主应用镜像。

使用发布镜像：

```bash
cd docs
docker compose up -d
```

基于当前源码本地构建：

```bash
cd docs
docker compose -f docker-compose.local.yml up -d --build
```

## 数据说明

`saas/multi-user` 分支的 Compose 会启动 Next.js、Go 后端和 PostgreSQL。未登录时，画布、我的素材、生成记录和 AI API Key 仍默认保存在浏览器本地；登录后，AI 请求会走后端 NewAPI 代理并使用额度系统。画布、素材和生成记录的云端 API 已提供，但现有页面的本地读写路径仍在逐步切换中。
